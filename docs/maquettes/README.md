# Maquettes validées

| Fichier | Écran | Largeur de référence |
| --- | --- | --- |
| `accueil-ordinateur.html` | Page d'accueil | 1 440 px |
| `consulting-ordinateur.html` | Landing Madal Consulting (gabarit des trois landings) | 1 440 px |
| `accueil-mobile.html` | Page d'accueil sur téléphone | 390 px |

Ouvrir les fichiers dans un navigateur. Ils servent de **référence visuelle** : structure des sections, hiérarchie, espacements, couleurs. Leur code (styles en ligne, hauteurs fixes) n'est pas à recopier : le site est construit en composants Astro avec `src/styles/tokens.css`.

Les textes entre crochets sont des contenus en attente (voir `docs/contenus-en-attente.md`).
